# שני בוטי הטלגרם

המערכת משתמשת ב**שני בוטים נפרדים**, ולא באחד. ההפרדה אינה קוסמטית — היא
מנגנון האבטחה היחיד שמפריד בין הבעלים לבין הלקוחות.

| בוט | למי | תהליך | מה הוא יודע |
|---|---|---|---|
| **#1 — מנהל** | לבעל העסק בלבד | WF9 (+ התראות מ-WF4b) | הכנסות, מספר חשבוניות, סכומים שלא שולמו |
| **#2 — לקוחות** | לכל לקוח | WF5 | מדיניות העסק וקטלוג המוצרים |

---

## יצירת הבוטים ב-BotFather

יצרתי שני בוטים דרך **@BotFather**:

```
/newbot
→ שם תצוגה:   AI Electronics — ניהול        (בוט #1)
→ שם משתמש:   ai_electronics_manager_bot     חייב להסתיים ב-bot
```

```
/newbot
→ שם תצוגה:   AI Electronics — שירות לקוחות  (בוט #2)
→ שם משתמש:   ai_electronics_support_bot
```

כל בוט מקבל טוקן בצורה `1234567890:AAH...`, וזה מה שמוזן ב-n8n.

### ההגדרות שקבעתי לבוט הלקוחות (#2)

```
/setdescription   → הבוט של איי.איי אלקטרוניקה. שאלו על מוצרים, משלוחים,
                    החזרות ואחריות.
/setabouttext     → שירות לקוחות אוטומטי — איי.איי אלקטרוניקה
/setcommands      → start - התחלת שיחה
```

### ההגדרות שקבעתי לבוט המנהל (#1)

```
/setdescription   → בוט ניהול פנימי. לבעל העסק בלבד.
/setjoingroups    → Disable   ← חשוב: מונע הוספה של הבוט לקבוצות
/setprivacy       → Enable
```

## השגת ה-Chat ID

ה-Chat ID הוא מספר שמזהה אתכם אישית בטלגרם. WF9 משתמש בו כדי לוודא ששואל
השאלה הוא באמת הבעלים.

השגתי אותו מתוך n8n: הרצתי את WF9 במצב בדיקה, שלחתי הודעה לבוט המנהל,
וקראתי את הפלט של צומת הטריגר:

```json
{
  "message": {
    "chat": { "id": 123456789, "first_name": "שי", "type": "private" },
    "text": "שלום"
  }
}
```

`message.chat.id` הוא המספר הדרוש.

אפשר גם לקבל אותו מהבוט `@userinfobot`.

## הזנת ה-Chat ID — שני מקומות

| תהליך | צומת | איפה בדיוק |
|---|---|---|
| **WF9** | `האם זה הבעלים` | בתנאי, בשדה הערך הימני |
| **WF4b** | `התראה למנהל` | בשדה Chat ID |

אותו מספר בשני המקומות. בקבצים שבתיקייה הוא מופיע כ-`000000000` — ערך זמני
שיש להחליף בהתקנה חדשה.

כל עוד המספר לא הוזן, התנאי אינו מתקיים לאף אחד וכל הודעה נופלת לענף
`סירוב גישה`. **ברירת המחדל היא לחסום** — וזו התנהגות מכוונת.

מחיקת התנאי במקום מילויו הייתה פותחת את נתוני ההכנסות לכל מי שמוצא את הבוט,
ולכן הוא נשאר חובה.
