# מסמכי מס ומע"מ בישראל

המערכת מיישמת כללי מס ישראליים בסיסיים. זהו פרויקט לימודי. שימוש בעסק אמיתי מחייב התייעצות עם רואה חשבון ועמידה
בדרישות רשות המסים, ובכלל זה חשבונית ישראל וממשק המספר המוקצה.

---

## שיעור המע"מ

| תקופה | שיעור |
|---|---|
| עד 31/12/2024 | 17% |
| מ-01/01/2025 | 18% |

החישוב יושב ב-WF1, בצומת `חישוב מעמ ומספר מסמך`, ומתבצע לפי **תאריך יצירת החשבונית**
ולא לפי התאריך הנוכחי:

```
שיעור     = Created >= 01/01/2025  ?  0.18  :  0.17
VatAmount = עיגול(Amount × שיעור, 2 ספרות)
Total     = עיגול(Amount + VatAmount, 2 ספרות)
```

השדה `Amount` הוא תמיד הסכום **לפני** מע"מ.

**דוגמה:** `Amount = 1,000` → `VatAmount = 180` → `Total = 1,180`.

---

## מספור מסמכים רץ

כל מסמך מקבל מספר עוקב בפורמט:

```
INV-2026-0001
INV-2026-0002
```

המספר נבנה ב-WF1: `'INV-' + שנה + '-' + (מספר החשבוניות הקיימות + 1)` מרופד
לארבע ספרות. הספירה נעשית בצומת `Summarize` — בלי קוד.

### ⚠️ מגבלה ידועה
שתי חשבוניות שנוצרות **באותו חלון סריקה** (אותה דקה) יקבלו את אותו מספר,
כי שתיהן סופרות את אותה כמות רשומות. בעסק אמיתי זו בעיה — חוק דורש מספור
ייחודי ורציף. הפתרונות המקובלים (טבלת מונים ייעודית עם נעילה, או Autonumber
של Airtable) הושמטו כאן בכוונה, לשם פשטות.

הביטוי בצומת `חישוב מעמ ומספר מסמך` מעדיף תמיד ערך קיים, כך ש-`InvoiceNumber`
שהוזן ידנית אינו נדרס.

## סוגי מסמכים

הדין הישראלי מבחין בין שלושה מסמכים:

| מסמך | מתי מוציאים | מה הוא מהווה |
|---|---|---|
| **חשבונית עסקה** | בעת ההזמנה | דרישת תשלום. אינה מזכה בניכוי מע"מ |
| **חשבונית מס** | בעת המכירה | מזכה את הקונה בניכוי מע"מ תשומות |
| **קבלה** | בעת קבלת התשלום | אישור על תקבול |

בפרויקט הזה כל הרשומות בטבלת `Invoices` מופקות כ**חשבונית מס**, והתבנית
ב-WF8 מכותרת בהתאם. הרחבה לשלושה סוגי מסמכים היא תרגיל להמשך: מוסיפים שדה
`DocType` לטבלה ותנאי `IF` ב-WF8 שבוחר כותרת ורצף מספור נפרדים.

## תבנית החשבונית

התבנית יושבת ב-WF8, בצומת `בניית HTML`, בשדה `html` — תיבת טקסט אחת עם
HTML בעברית RTL.

**מה יש בתבנית:**
- כותרת עסק: שם, ח.פ., כתובת, טלפון ומייל
- כותרת "חשבונית מס" + מספר המסמך + תאריך בפורמט `dd/mm/yyyy`
- פרטי הלקוח (`CustomerId`)
- טבלת פריטים
- פירוט: סכום לפני מע"מ · מע"מ באחוזים ובשקלים · סה"כ לתשלום
- הערת שוליים על שיעור המע"מ החוקי במועד העסקה וחובת השמירה לצורכי דיווח
- חותמת "מקור"

פרטי העסק בתבנית הם של העסק הבדיוני שבפרויקט
(`איי.איי אלקטרוניקה בע"מ`, `ח.פ. 515123456`, `רח' הברזל 12, תל אביב`).

הסכומים מוצגים עם הפרדת אלפים ושתי ספרות אחרי הנקודה, בפורמט `he-IL`,
והתאריך בפורמט ישראלי — שני אלה מוכנים מראש בצומת `הכנת נתוני המסמך`
כדי שהתבנית עצמה תישאר קריאה.

---

## ההמרה ל-PDF

התבנית היא HTML, וההמרה ל-PDF מתבצעת ב-**PDFShift** — שירות שמרנדר את הדף
בדפדפן Chrome אמיתי ומחזיר קובץ. כך המסמך הסופי יוצא **זהה בדיוק** לתצוגה
בדפדפן: העברית, ה-RTL, הכותרת הכחולה, הטבלה והחותמת.

בתהליך זהו הצומת `המרה ל-PDF` — בקשת HTTP אחת שמקבלת את ה-HTML ומחזירה
את הקובץ הבינארי, שעולה משם ישירות לגוגל דרייב בשם `INV-2026-0001.pdf`.

## מה המערכת לא עושה

- אינה מדווחת לרשות המסים ואינה מתחברת למערכת חשבונית ישראל
- אינה מפיקה קבלות או חשבוניות זיכוי
- אינה מטפלת בעסקאות פטורות ממע"מ, בייצוא או במע"מ בשיעור אפס
- אינה מנהלת ספרי הנהלת חשבונות
- אינה שומרת עותק ארכיוני בלתי ניתן לשינוי

מסמך המדיניות `data/policies/06-israeli-tax-invoice-rules.md` מכיל את הכללים
המלאים כפי שהסוכן מכיר אותם, והוא מה שסוכן שירות הלקוחות שולף כשלקוח שואל
על חשבוניות ומע"מ.
